The old stuff

Everything here ran on the original ranzlappen.com before it became a Jekyll blog — a pile of hand-written HTML, jQuery-era JavaScript and PHP talking to a MySQL database on shared hosting.

That server is gone. These pages are hosted on GitHub Pages, which serves static files and nothing else, so every project that needed PHP has been rewritten to run in your browser instead. Same features, no backend — see how the conversion works.

  • 🎲

    Dice Cube

    A CSS-3D cube you tumble face to face with edge buttons, or spin at random. Six emoji faces, no library.

    Always JS was Project0/wurfel.html

  • 🎼

    Sheet Music Editor

    Drop Unicode music glyphs onto printable A4 staves, drag them around, save and reload the score as XML.

    Always JS was Project1/Sheet.html

  • ⚔️

    GW2 Trading Post

    Look up Guild Wars 2 item buy/sell listings by name or ID, divide prices by a per-item cost, and sort to find the best conversion.

    Always JS was Project2/gw2.html

  • 📷

    Barcode Scanner

    Scan EAN, UPC and Code 128 barcodes with the device camera, build a quantity list and export it as CSV.

    Always JS was barcode/barcode.html

  • 🗃️

    Code Snippet Database

    Store snippets by language with two free-text fields, filter across all columns, and preview any HTML snippet in a sandboxed frame.

    MySQL → localStorage was Project5/index.php

  • 📦

    3D Container Packing

    Set a container size, add boxes, and watch a shelf-packing pass lay them out in an orbitable Three.js scene.

    PHP session → localStorage was Project6/index.php

  • 🗄️

    File Vault

    Upload files, mark them private or released, and download them back. Storage moved from the server's uploads/ to IndexedDB.

    MySQL + uploads → IndexedDB was Project3/

  • 🧑‍💻

    Live HTML Editor

    Type HTML and CSS, see it render live, click elements in the preview to apply style presets, and export the result as a file.

    PHP zip → in-browser export was devtools_project/

  • ⛏️

    Minecraft Command Console

    The original piped commands into a server's screen session. Now it's a command builder: compose, validate and copy commands to run yourself.

    shell_exec → builder was Project4/

  • 🔐

    Secret Image

    A passphrase gate in front of a picture. Rebuilt honestly: the image is genuinely encrypted with the passphrase, not just hidden by CSS.

  • 🃏
