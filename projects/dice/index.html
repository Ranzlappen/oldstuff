Dice Cube

Six emoji faces on a CSS-3D cube. The arrow buttons tumble it one quarter turn at a time; Roll throws it into a chaotic spin and lands on a random face. Arrow keys work too, and Space rolls.

Originally public_html/Project0/wurfel.html. It was already pure HTML, CSS and JavaScript, so nothing had to be converted — the face bookkeeping was rewritten to derive orientation from the cube's actual rotation instead of a hand-written lookup table, which fixes the two "left2"/"back2" special cases the original needed.
