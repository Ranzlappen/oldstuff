File Vault

Drop files in, give them a name, mark them released so they show up in the shared list, and download them back out.

This is local storage, not a file host. The original uploaded to a server directory and tracked ownership in MySQL behind a login. There is no server here, so files are kept in this browser's IndexedDB — they never leave your device and nobody else can see them. Clearing site data for this domain deletes them.
