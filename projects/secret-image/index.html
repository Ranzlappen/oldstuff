Enter the passphrase to reveal the picture.

How this one works

The original checked the passphrase in PHP and, if it matched, served the file. A static host cannot do that — anything it can serve, it will serve to anyone who asks for the URL. So the check would have been decoration: the image would sit at a guessable path, and the "gate" would be a display: none anyone could step around with developer tools.

Instead the image really is encrypted. secret.bin is AES-256-GCM ciphertext; the key is derived from your passphrase with PBKDF2-HMAC-SHA256 over 250,000 iterations, using a salt stored in the file's first 16 bytes. A wrong passphrase fails GCM's authentication tag and produces nothing at all — there is no plaintext on the server to leak.

This is a demonstration, not a vault. The ciphertext is public and the passphrase is short, so it would not survive a determined offline attack. The point is that the gate is real rather than cosmetic — don't put anything you actually care about behind it.
